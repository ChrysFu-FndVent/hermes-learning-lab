# 课程衡量指标

项目默认不加载第三方分析脚本，也不上传学习进度。以下是上线后的最小衡量方案，避免为了统计而收集 Prompt、回执或身份信息。

| 指标 | 定义 | 推荐来源 |
|---|---|---|
| Pages 访问 | 在线课程页面的去重访问和回访 | 经隐私审查后的 Pages 分析工具 |
| 第一课进入率 | 从 README 访问在线站点并看到 Lesson 00 的会话比例 | README CTA 的活动参数 + 页面浏览事件 |
| 课程反馈数 | General、Q&A 和 Ideas 中与课程相关的有效讨论 | GitHub Discussions |
| 毕业项目展示数 | Show and tell 中包含验收证据与恢复说明的项目 | GitHub Discussions |
| 回访量 | 同一匿名设备在不同日期再次访问课程 | 仅在用户同意后使用匿名分析 |

## 隐私边界

- 不采集 Prompt、Hermes 回复、实验回执、Token、App Secret 或本地路径。
- 不把 `localStorage` 学习进度发送到远端。
- 启用分析前必须在 README 和站点中写明提供方、字段、保留期和退出方式。
- 没有分析服务时，不应把 GitHub Stars 或仓库浏览量误称为课程完成率。

## 发布复盘

每次课程版本更新后记录：发布日期、Hermes 核验版本、Pages 可用性、CI 结果、主要反馈主题和下一轮要修复的高频阻塞点。
